## 1. The UI is generated by the closure kernel

The relevant direction is:

\[
\boxed{
\text{learner-side witnesses}
\Longrightarrow
\text{generated map relation}
\Longrightarrow
\text{hair/view atlas}.
}
\]

There is no admitted independent UI coordinate system. A `WitnessedKernel`
contains only:

```text
admitted values
bounded occurrences and generated depth
domain WHY, perspective WHY, and goal WHY
attempts
return receipts
```

It contains no colour, mesh, card, screen position, chart, or drawing.

The source-derived canonical map names:

```text
core → brain/current perspective → value → belief → WHY/reason → goal
  → lesson → project → impact → balance → Slearn → world/dream
```

and includes the perspective-to-goal ascent, the lesson/project 90-degree turn,
project descent, equal-depth rungs, and WHY links. `GenNode` and `GenLink` admit only the parts
licensed by the kernel:

| Map element | Required kernel evidence |
| --- | --- |
| Value | Admitted value |
| Belief | The same admitted value in the belief reading |
| WHY/reason, goal, lesson / lesson ascent / WHY link | All three WHY witnesses |
| Project / project descent / project impact | Attempt |
| Lesson–project turn and equal-depth rung | WHY witnesses and attempt |
| Returned experience reading | Return receipt |

The theorem `saturated_generatedMap` proves that when every occurrence within
the selected bounds has all three WHY witnesses and an attempt, the generated
node/link relation equals the canonical bounded map. This is not a uniqueness
theorem for all interfaces and does not derive the source topology from no
assumptions. It proves the precise direction needed to reject arbitrary UI:

\[
\text{witnessed bounded kernel}
\Longrightarrow
\text{the specified Slearn map}.
\]

Conversely, unwitnessed reasons, goals, lessons, and unattempted projects have
no generated node. Two kernels with the same bounds and generated nodes agree
on the visible WHY witnesses and attempts inside those bounds. A spatial
runtime may lay the admitted topology out as the specified triangle and turn,
but may not independently add a node, edge, control, or runtime state.

## 2. Experience, zoom, and hair

A receipt changes an occurrence from `prospective` to `returned`; it does not
change the lesson/project topology. A completion display is therefore never a
substitute for the receipt that admitted it.

Zoom remains a Galois-style pair of readings of one maintained translation:

\[
\operatorname{ZoomOut}(f)\preceq c
\iff
f\preceq\operatorname{ZoomIn}(c).
\]

The inward reading is the recorded translation. The flip is an orientation
change, not literal equality of two interfaces.

The hair is an atlas of local viewports with transitions. The finite module
uses a stated quarter-turn transport only to prove a narrow fact: its globally
coherent direction must be zero. This makes zero/grey directions positive map
information rather than rendering defects. It is not a theorem about a
physical bundle, space-time, consciousness, or matter.

`PATH`, `OBSTRUCTION`, and `OPEN` remain map states. In particular, missing
representational support produces `OPEN` and cannot be displayed as `PATH`.

## 3. Directional tokens and resuperposition

A `PerspectiveToken` is subject-assigned and dimension-indexed:

\[
\tau=(\text{subject},\text{dimension},\text{payload},\text{phase},
\text{time index}).
\]

Its `MetaVector` retains the dimension, a phase coordinate, and an ordered
time coordinate. These are representation fields; phase is not automatically
the complex unit, and time is not automatically physical time.

The "Kakeya grain" is represented by an `AssumptionGrain`:

\[
K(A)=\{d:\exists a\in A,\;a\text{ permits }d\}.
\]

It makes assumptions and their permitted directions inspectable. A narrower
grain can remove directions but cannot invent a direction unavailable in the
prior grain. Such a removal must appear as a selected restriction, an
obstruction, or `OPEN`; it cannot silently collapse the map.

Token relationships are `resonant`, `dissonant`, or `open` within a specified
network. They are not popularity, morality, or truth scores.

A subject assignment is not IVI by itself. A token becomes
`IntangiblyVerified` in this structural model only through a return receipt
carrying a caller-supplied grounding obligation. The type records that
obligation; it does not manufacture empirical independence.

## 4. Chaitin/Kakeya as roles in one closure cycle

The cycle is:

\[
\boxed{
\Delta_t(A)
\xrightarrow{\text{finite token realizations}}
\operatorname{Ch}_t
\xrightarrow{\text{returned basis}}
\operatorname{Ka}_t
\Delta_{t+1}(A').
}
\]

`ChaitinKakeyaCycle` calls the first arrow `contract` and the second `reopen`:

\[
\operatorname{contract}:R\to B,
\qquad
\operatorname{reopen}:B\to D\to\operatorname{Prop}.
\]

Thus resuperposition is not retaining every alternative forever. It is
reopening a directional field from a returned basis while retaining a
comparator-defined residue:

\[
\exists r'\!:\;
\operatorname{basis}(r')=\operatorname{basis}(r)
\land
\Omega(r')\ne\Omega(r).
\]

The ordered `MetaVectorTrace` is the formal place for tip-to-tail history.
When a visible state returns, the trace can retain a nonempty ordered
dimension-history. This is the token/dimension reading of holonomy, not a
physical assertion about time.

## 5. Combined runtime admission rule

The UI and token layers meet at a strict receipt boundary:

```text
assumption grain → available directional token field
  → resonance / dissonance / OPEN interactions
  → WHY-witnessed lesson and attempted project relation
  → independently grounded return receipt
  → prospective-to-returned experience reading
  → comparator residue and inherited continuation field
  → generated Slearn map at the next orientation/zoom
```

No calendar, chat, card, token display, 3D object, metric, or recommendation is
admitted as an independent mechanic. It must be generated from, or act as a
transparent control for, a state in this relation.
