# Slearn education model

## Purpose

Slearn is an educational framework for people who want to connect what they
know, why they care, and where they are trying to go. It does not treat a goal,
a value, a source, or a lesson as an isolated object. Each becomes useful only
as part of a revisable relation.

The product problem is practical: conventional learning tools can deliver
facts, courses, feeds, and tasks, while leaving a learner's perspective,
assumptions, reasons, and goals disconnected. Slearn is intended to make those
connections visible and revisable over time.

## Learning cycle

```text
current perspective
  → WHY relation
  → chosen direction
  → source / lesson / project
  → attempted return
  → revised perspective
```

The return is not a claim that the learner has reached a final answer. It
records a concrete change in how the learner reads the relation after an
attempt. A relative re-reading and preserved bridge are required before a
topic can contract to a shared direction or reopen as a new local path.

## Current interactive runtime

The runtime presents one spatial learning field. A learner can:

- state a current perspective, WHY relation, and chosen direction;
- add a source, observation, conversation, lesson, or project to that path;
- record an attempt, the return evidence, and a successor perspective;
- contract a bridged path to its shared direction, reopen it, or return it as a
  successor perspective;
- record a natural, dual, or obstructed relative position rather than forcing a
  path to appear successful.

The visible learning field is derived from those records. Sources attach to a
WHY relation; lessons are traversable readings of a direction; projects are
visible only when an attempt is present; successor perspectives require the
complete return evidence. The runtime intentionally has no topic folders,
independent navigation tree, or recommendation score.

## Theory and scope

The framework is informed by Socratic questioning, perspective and limits of
reason, and dialogical/holistic approaches to learning. These are educational
and philosophical inspirations, not machine-checked claims about physics,
consciousness, or the nature of the universe.

The present implementation does not yet retrieve external sources, infer a
learner's beliefs, validate return evidence, or connect people’s maps. Those
are future product questions. A person supplies and revises their own
relations; any AI assistance would need to remain transparent about its sources
and suggestions.
